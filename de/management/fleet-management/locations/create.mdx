## Wofür diese Seite da ist

Mit diesem Formular erfassen Sie einen neuen Standort.

## Was Sie hier tun können

- Einen Standortnamen wählen.
- Den Standorttyp festlegen.
- Einen Bereich oder eine Form auf der Karte einstellen.

## Screenshot

![Standort anlegen](/images/de/captures/management-locaties-aanmaken.png)

## Was Sie auf der Seite sehen

- Felder für Name und Standorttyp.
- Einstellungen für den Bereich, etwa einen Kreis oder einen anderen überwachten Bereich.
- Einen Kartenbereich, um den Standort genau einzustellen.

## So nutzen Sie diese Seite

1. Geben Sie dem Standort einen eindeutigen Namen.
2. Wählen Sie den passenden Standorttyp.
3. Stellen Sie den Bereich auf der Karte so genau wie möglich ein.
4. Speichern Sie den Standort.

## Was danach passiert

- Der neue Standort erscheint in der Übersicht.
- Kolleginnen und Kollegen können den Standort anschließend in relevanten Abläufen verwenden.

## Wichtig zu wissen

- Arbeiten Sie genau, wenn der Kartenstandort für die Erkennung oder Erfassung wichtig ist.
- Verwenden Sie einen Namen, den auch Kolleginnen und Kollegen sofort verstehen.

## Verwandte Seiten

- Übersicht der Standorte
- Karte
