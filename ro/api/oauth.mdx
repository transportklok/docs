## Cum funcționează

TransportKlok folosește OAuth 2.0 cu fluxul authorization code. Aplicația dumneavoastră trimite utilizatorul către TransportKlok. Acolo utilizatorul se autentifică, alege organizațiile și își dă acordul. Aplicația dumneavoastră schimbă apoi un cod pe un token de acces și un token de reîmprospătare.

## Solicitarea unui client

Un client OAuth îl solicitați de la TransportKlok la [info@transportklok.nl](mailto:info@transportklok.nl). Indicați:

- numele, o descriere, un logo și site-ul aplicației dumneavoastră;
- adresele de redirecționare (redirect URL) către care TransportKlok trimite utilizatorul după acordarea accesului;
- scope-urile de care are nevoie aplicația dumneavoastră;
- dacă aplicația dumneavoastră este pentru administratori sau pentru angajați.

Primiți un ID de client și, pentru o aplicație cu server propriu, un secret de client.

## Pașii

1. Trimiteți utilizatorul la adresa de autorizare:

   ```text
   https://app.transportklok.nl/oauth/authorize
     ?client_id=<client-id>
     &redirect_uri=<redirect-url>
     &response_type=code
     &scope=<scopes, met spaties ertussen>
     &state=<willekeurige waarde>
   ```

2. Utilizatorul vede **Autorizați aplicația**, alege la **Organizații permise** organizațiile și face clic pe **Permiteți**.
3. TransportKlok trimite utilizatorul înapoi la adresa dumneavoastră de redirecționare cu `code` și `state`. Verificați că `state` este identic cu ce ați trimis.
4. Schimbați codul pe un token:

   ```http
   POST /oauth/token HTTP/1.1
   Host: app.transportklok.nl
   Content-Type: application/x-www-form-urlencoded

   grant_type=authorization_code&client_id=<client-id>&client_secret=<client-secret>&redirect_uri=<redirect-url>&code=<code>
   ```

5. Răspunsul conține `access_token`, `refresh_token`, `token_type` și `expires_in` (în secunde).

## Obținerea unui token nou

Dacă tokenul de acces a expirat, solicitați unul nou cu tokenul de reîmprospătare:

```http
POST /oauth/token HTTP/1.1
Host: app.transportklok.nl
Content-Type: application/x-www-form-urlencoded

grant_type=refresh_token&client_id=<client-id>&client_secret=<client-secret>&refresh_token=<refresh-token>
```

## Ce vede utilizatorul

La acordarea accesului, utilizatorul vede ce aplicație solicită acces, cu ce cont și cu ce permisiuni. Accesul îl revocă utilizatorul la **Setări** → **Aplicații** în TransportKlok.
