## Wofür diese Seite da ist

Mit einer Erfassungsvorlage legen Sie fest, welche Tätigkeiten eine Gruppe von Mitarbeitenden an einem Arbeitstag erfasst. Ein Fahrer erfasst so andere Dinge als jemand im Büro.

## Wer das nutzen darf

- Ein Administrator oder Manager des Teams.

## So nutzen Sie diese Seite

1. Öffnen Sie **Einstellungen**, wählen Sie das Team und wählen Sie **Erfassungsvorlagen**.
2. Legen Sie einen neuen Arbeitstag an.
3. Tragen Sie den **Name** ein, wählen Sie die **Aktivitäten** und geben Sie an, ob der Arbeitstag **Wiederholbar** ist.
4. Klicken Sie auf **Speichern**.
5. Mit **Bearbeiten** passen Sie eine Erfassungsvorlage an, mit **Entfernen** nehmen Sie sie heraus.

## Felder

| Feld | Was Sie eintragen |
|------|--------------|
| **Name** | Der Name des Arbeitstags. |
| **Aktivitäten** | Die Tätigkeiten, die zu diesem Arbeitstag gehören. |
| **Wiederholbar** | Ob der Arbeitstag mehrfach hintereinander erfasst werden kann. |

## Was danach passiert

- Mitarbeitende erfassen mit der Erfassungsvorlage nur die Tätigkeiten, die darin stehen.
- Eine gelöschte Erfassungsvorlage steht auf dem Tab **Papierkorb**. Mit **Wiederherstellen** stellen Sie sie wieder her.

## Einschränkungen

- Eine Erfassungsvorlage gilt innerhalb des Teams, in dem Sie sie anlegen.
