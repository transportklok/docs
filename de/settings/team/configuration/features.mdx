## Wofür diese Seite da ist

Hier schalten Sie zusätzliche Funktionen für ein einzelnes Team ein oder aus.

## Wer das nutzen darf

- Ein Administrator oder Manager des Teams.

## So nutzen Sie diese Seite

1. Öffnen Sie **Einstellungen**, wählen Sie das Team, wählen Sie **Konfiguration und Funktionen** und öffnen Sie den Tab **Funktionen**.
2. Klicken Sie auf **Funktion hinzufügen** und wählen Sie **Aktivieren**, oder klicken Sie bei einer aktiven Funktion auf **Deaktivieren**.
3. Klicken Sie bei einer Funktion auf **Einstellungen**, um diese Funktion einzustellen.

## Felder

| Spalte | Bedeutung |
|-------|-----------|
| **Name** | Die Funktion. |
| **Beschreibung** | Was die Funktion tut. |
| **Verwendet** | Welches Modul die Funktion benötigt. |
| **Kosten** | Was die Funktion pro Mitarbeitenden pro Monat kostet, oder **Kostenlos**. |

## Was danach passiert

- Eine aktivierte Funktion steht dem Team zur Verfügung. Bei einer geplanten Änderung sehen Sie `Wordt actief vanaf` oder `Wordt inactief vanaf` mit dem Datum. Mit **Aktivierung stoppen** oder **Deaktivierung stoppen** machen Sie sie rückgängig.

## Einschränkungen

- Eine Funktion verwendet ein Modul der Organisation. Siehe [Module](/de/settings/organization/configuration/modules).
