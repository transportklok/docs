## Wofür diese Seite da ist

Hier erfassen Sie Stunden, in denen Sie nicht gearbeitet haben, etwa Urlaub, Krankheit, einen Feiertag oder Ruhezeit.

## Screenshot

<img src="/images/de/captures/app-verlof-uren.png" alt="Nicht produktive Stunden erfassen" width="320" />

## Wer das nutzen darf

- Jeder Mitarbeitende, der die App nutzt.

## So nutzen Sie diese Seite

1. Tippen Sie auf der **Startseite** auf **Urlaub registrieren**. **Nicht produktiv (Urlaub, Standtag (overstaan) oder Ruhezeit)** ist bereits gewählt.
2. Wählen Sie das **Datum** und tippen Sie auf **Weiter**.
3. Wählen Sie bei **Team** Ihr Team und tippen Sie auf **Weiter**.
4. Tippen Sie bei **Nicht produktive Stunden** auf **Tätigkeit hinzufügen** und wählen Sie die Art der Stunden.
5. Tragen Sie die Zeiten ein und fügen Sie Ihre **Unterschrift** hinzu.
6. Tippen Sie auf **Abschließen**.

## Felder

| Art der Stunden | Wann Sie dies wählen |
|------------|---------------------|
| **Arbeitszeitverkürzung (ATV)** | Arbeitszeitverkürzung. |
| **Urlaub** | Gewöhnlicher Urlaub. |
| **Sonderurlaub** | Urlaub für ein besonderes Ereignis. |
| **Krank** | Sie waren krank. |
| **Feiertag** | Ein anerkannter Feiertag. |
| **Unbezahlter Urlaub** | Urlaub ohne Lohn. |
| **Standtag (overstaan)** | Wartezeit ohne Ihr Verschulden. |
| **Bereitschaftsdienst** | Sie waren abrufbereit. |
| **Ruhezeit** | Ihre vorgeschriebene Ruhezeit. |

<Hint kind="grey">Welche Arten Sie sehen, hängt davon ab, was Ihr Arbeitgeber für Ihr Team eingestellt hat.</Hint>

## Was danach passiert

- Der Eintrag steht in der [Übersicht](/de/workforce/app/overview) und wartet auf die Genehmigung Ihres Arbeitgebers.

## Einschränkungen

- Ist der Abrechnungszeitraum dieses Tages bereits verarbeitet, können Sie dafür keine Stunden mehr erfassen.
