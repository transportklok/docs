## What this page is for

Here you create a payroll run for a pay period. The run starts as a draft, so that you can check it before you process it.

## Screenshot

![Create payroll run](/images/nl/captures/management-salarisrondes-aanmaken.png)

## Who can use this

- An administrator with full rights in the organization.
- The organization needs the **Payroll inputs** module.

## How to use this page

1. Open **HR** → **Payroll administration** → **Payroll runs**.
2. Click **New period**.
3. Choose the **Payroll period**.
4. Click **Create draft**.

## Fields

| Field | What you fill in |
|------|--------------|
| **Payroll period** (required) | The pay period of the run, for example `Periode 2026-08`. You choose from the periods that do not have a run yet. |

## What happens next

- You return to the overview. The new run is calculated right away and stays at **Running** for the time being.
- After that, the run has the status **Draft**.
- You continue with locking and completing. See [Process payroll run](/en/management/human-resources/payroll-runs/process).

## Limitations

- You only create runs for periods up to and including today. If a run already exists for every period, you see **All payroll periods up to today already exist.**
- There is one run per period: a period with a run is no longer in the selection list.
